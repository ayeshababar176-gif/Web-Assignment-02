## Explanation

CSS (Cascading Style Sheets) is a stylesheet language used to control the presentation of HTML documents. It helps developers set colors, fonts, backgrounds, borders, spacing, and page layouts. Separating presentation from content can make a website easier to maintain and gives multiple pages a consistent appearance.

In the rule `p { color: #382d49; }`, `p` is the selector, `color` is the property, and `#382d49` is the value. The selector chooses the paragraph elements, the property identifies what is changed, and the value specifies the text color.

There are three common ways to apply CSS. Inline CSS is written in an HTML element's `style` attribute and is used on the Home page in this project. Embedded CSS is written inside a `<style>` element in the document's `<head>` and is used on the Information page. External CSS is stored in a separate `.css` file and connected using a `<link>` element; this method styles the Project Inquiry page. External stylesheets are useful for reusing styles and maintaining consistency.

CSS1 introduced the core styling features. CSS2 expanded styling and layout capabilities, while CSS 2.1 clarified and corrected parts of CSS2. Modern CSS is developed in separate modules, allowing features such as Flexbox, Grid, media queries, and transitions to evolve independently.

Browser support matters because browsers may implement features differently. Test this website in two browsers, such as Google Chrome and Mozilla Firefox, and record any visible differences. Semantic HTML examples in this project include `<header>`, `<nav>`, `<main>`, `<article>`, and `<footer>`, because they describe the purpose of their content. A `<div>` is a non-semantic generic container because it does not describe the meaning of its content.
